# Local AI Guidance

- Mark AI-produced or substantially AI-assisted comments and documentation with `✨` when practical.
- For documents that are mostly AI-produced, prefer one document-level `✨` attribution note instead of marking every paragraph.
- Treat `✨` as a provenance marker, not decorative content.
- Before writing, picking up or working a ticket in `.scratch/`, read `docs/agents/issue-tracker.md`: it holds the ticket shape and the rules for reading the spec, agreeing tests and resolving.
- How the project has been built with AI, and the tools for it, is in `docs/ai-workflow.md`.
- The content owner's documents, where a developer keeps them, sit at the repo root, untracked: `Whatever You Do feedback - checklist.md` (their feedback, ticked as each item is checked) and `Whatever You Do - wording changes.md` (the wording they are shown; record any new or changed participant-facing wording there).
