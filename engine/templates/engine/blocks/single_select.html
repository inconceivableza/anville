The empty option always leads, placeholder or not: a select with none marked shows its first option, which would look like an answer never given. What is sent is the option's identifier; the server refuses anything that is not one of this block's options. In a wizard (`choices_as_cards`) the options are v3's cards instead, each a radio, saving as soon as one is chosen; nothing is checked until one is, so nothing is sent, and the wizard's gate asks for one. With no empty option to go back to, a choice can be changed but not cleared, as v3's cards are. Either way its fields belong to the page's one form (`engine/page_form.html`), under the block's own name, so that without JavaScript every press on the page, its Save or its way on, sends the choice with every other answer (sprint-3d-r1-fix-6); this form only holds it in place, with its status.
